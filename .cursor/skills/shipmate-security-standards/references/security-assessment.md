# Security Assessment

Use this reference when you need a structured security analysis workflow rather
than a lightweight implementation checklist.

## What It Covers

- Security code review pipelines
- Penetration-testing and red-team style workflows
- Threat-modeling pipelines

## When To Reach For It

- You are doing a dedicated security review, not just a merge checklist.
- The task needs a formal threat model or attack-surface analysis.
- The change is high risk and needs a more methodical breakdown by vulnerability class.

## Best Fit

This prompt family is reactive and assessment-oriented. Use it when the work
needs a formal review motion, deeper triage, or explicit threat-model artifacts.
