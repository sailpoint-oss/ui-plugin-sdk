# AI Coding Requirements Prompts

Use this reference when security expectations must become explicit,
testable requirements for implementation planning.

## What It Covers

- Turning raw context into structured requirements
- Adding security requirements as numbered, verifiable constraints
- Mapping requirements to verification methods and implementation batches

## When To Reach For It

- Planning or specification work needs stronger security requirements.
- A team needs clear MUST or MUST NOT statements instead of informal guidance.
- You want security controls traced into tests, reviews, and delivery slices.

## Best Fit

This prompt family is best during planning and spec work, especially when a
security concern needs to become a concrete requirement instead of a vague note.
