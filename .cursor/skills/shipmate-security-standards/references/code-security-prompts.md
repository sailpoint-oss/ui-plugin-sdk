# Code Security Prompts

Use this reference when the task needs deeper secure coding guidance than the
global baseline alone can provide.

## What It Covers

- Technology-specific secure coding patterns
- Backend, frontend, infrastructure, mobile, and AI security topics
- Cross-cutting web and API security issues
- Authorization and policy-driven access control

## When To Reach For It

- You need deeper patterns for a specific platform or framework.
- The review involves injection, authz, file handling, or web/API hardening details.
- A generic "validate input" answer is not enough to guide implementation.

## Best Fit

This prompt family is best for proactive secure-by-default coding guidance.
It is not the right first choice for incident response or formal threat modeling.
