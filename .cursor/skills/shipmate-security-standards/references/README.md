# Manicode Prompt Catalog

This bundled reference summarizes the prompt families most relevant to the
global `security-standards` skill. Use it when the baseline checklist is not
enough and you need a deeper security workflow.

## Read This First

- Use `./code-security-prompts.md` for deeper secure-by-default coding patterns.
- Use `./security-assessment.md` for structured review, pentest, or threat-model flows.
- Use `./validation-prompts.md` for AI guardrails, runtime validation, and abuse controls.
- Use `./ai-coding-requirements-prompts.md` when security requirements need to become
  explicit, testable implementation constraints.

## Secondary Reference

The original prompt library also contains workforce-role prompts. Those can help
with specialized personas, but they are not part of the global security baseline
and should not be your first stop during normal implementation or review work.
